Live view of every Jev call

Overview

A live view of every request sent to Jev and every answer returned.

My role

I specified the behaviour and the commands, then tested and corrected it. Built with Claude Code, which wrote the code.

Outcome

I can watch Jev work in real time. A call that gets no answer is recorded, not lost.

Note

It runs on a single Mac and has no public demo.

Outcome

A short brief becomes a finished page that Jev has graded.

Note

No outside reviewer has rated the pages.

Switch between Jev and a local model

Overview

A single switch that points my tools at Jev or at an open model that runs on my own Mac.

My role

I directed the switch and the local setup, built with Claude Code. Credit to convaiinnovations for the open model and mizorewww for its Apple Core ML version.

Outcome

The switch moves my tools between Jev and the local model. Nothing breaks when I switch.

Note

I do not say it beats Jev, because the two were never tested on the same task.

Paste code, get a Webflow page

Overview

Turns pasted HTML and CSS into native Webflow elements that follow the site’s own styles.

My role

I set the rules it works under, including never overwriting an existing style, and tested it in my own Webflow Designer. Built with Claude Code.

Outcome

Pasted code becomes native Webflow elements that reuse the site’s styles. Pasting a newer version replaces the old block.

Note

Proven on test pages. Live use has only just begun.
